# Tareas de contenido (C-NN)

Mismo pipeline que Agent Engineering v3.0: `content.py` → HTML plano por bloque (secciones con IntersectionObserver, hash routing, theme switcher), labs en Markdown, mini-quiz de 3 preguntas por bloque, prosa de autoestudio (no guion de instructor).

Convenciones:
- Bloque = 25–40 slides + 1 lab (excepto curso 4: sin labs de código, con ejercicio de plantilla).
- Cada slide: título, idea única, ejemplo real o del caso conductor, nada de relleno.
- Toda afirmación normativa con artículo/fuente y fecha de verificación. Nunca inventar plazos.
- Cierre de bloque: "qué te llevas" (3 puntos) + mini-quiz + enlace al siguiente.
- Orden de producción: C-00 → C-02..C-08 (curso 3) → C-01 → C-09..C-14 (curso 4) → C-15 (pack seguros) → resto de packs → C-21.
